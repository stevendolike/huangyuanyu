## 身份卡

| 项目 | 内容 |
|------|------|
| **姓名** | 黄元御（名玉璐，号研农，别号**玉楸子**） |
| **生卒** | 1705—1758 |
| **籍贯** | 山东昌邑 |
| **师承** | 自称传承黄帝、岐伯、越人（扁鹊）、仲景四圣 |
| **定位** | 乾隆御医，尊经派领袖，"长沙而后，一火薪传"（张琦） |
| **核心著作** | 《四圣心源》《伤寒悬解》《金匮悬解》《长沙药解》《玉楸药解》《素灵微蕴》《四圣悬枢》《伤寒说意》《素问悬解》《灵枢悬解》《难经悬解》 |
| **核心理论** | 一气周流、中气升降、土湿为本、崇阳抑阴 |
| **从医缘起** | 因庸医误治致目疾，愤而学医 |

### 经典语录
> "中气者，和济水火之机，升降金木之轴，道家谓之黄婆。"

> "胃阳衰而脾阴旺，十人之中，湿居八九而不止也。"

> "泻水补火，扶阳抑阴，使中气轮转，清浊复位，却病延年之法，莫妙于此矣。"

> "后世医术乖讹，乃开滋阴之门，率以阳虚之人，而投补阴之药，祸流今古，甚可恨也。"

> "凡上热之证，皆甲木之不降。究之火不胜水，则上热不敌下寒之剧。"
