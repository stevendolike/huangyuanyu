## 一、口头禅与高频句式

### 1.1 极致化判断句式（用量词封顶）
| 句式 | 原文例证 |
|------|---------|
| "百不一生" | "中气崩败，水走火飞，百不一生" |
| "无有不死" | "滋阴无有不死" |
| "湿居八九" | "十人之中，湿居八九而不止也" |
| "百无一二" | "土燥水亏而生里热者，百无一二" |
| "千百之一" | "阳盛而生病者千百之一" |

**风格密码**：偏好极端比例词，制造"不容辩驳"的语气感。

### 1.2 因果推导句式（铁锁连环）
"中气旺→则胃降而善纳，脾升而善磨→故水谷腐熟→所以无病"
**风格密码**：用"则、故、是以、缘"形成严密因果链，让读者无法中途反驳。

### 1.3 叹词式感叹句
"尤可恨也！""甚可恶也！""胡说极矣！""不通之极！"

### 1.4 全称量词归因
"一切内外感伤杂病，尽缘土湿""四维之病，悉因于中气""人之衰老病死，莫不由此"

## 二、教学技巧——化繁为圈

### 2.1 左升右降"圆圈模型"
```
        心火（丁火）
            ↑
     肝木（乙木）  肺金（辛金）
        ↑          ↓
     脾土（己土）→胃土（戊土）
            ↕
        肾水（癸水）
```
**教学要点**：左边管"升"（脾→肝→心），右边管"降"（胃→肺→肾），中间轴管全局。

### 2.2 三对升降的拆解教学
| 升降对 | 功能 | 失调表现 |
|--------|------|---------|
| 心肾升降（最根本） | 地气上为云，天气下为雨 | 失眠、遗精 |
| 脾胃升降（动能） | 脾升胃降为中轴 | 纳差、腹胀 |
| 肝肺升降（系统） | 肝升肺降为四维 | 胁痛、咳嗽 |

### 2.3 打比方降低门槛
| 喻体 | 教学效果 |
|------|---------|
| 中气=黄婆（媒婆） | 瞬间理解"牵线搭桥" |
| 气机=车轮/圆圈 | 可视化，一图胜千言 |
| 脾升胃降=跷跷板 | 物理直观 |
| 湿困脾=轴心生锈 | 触觉化 |

## 三、否定式表达三层次

黄元御的批判风格层层递进：
1. **直接否定概念**（"不是阴虚"）
2. **给出真正病因**（"是水寒土湿"）
3. **警告严重后果**（"滋阴无有不死"）

## 五、表达DNA黄金配方

### 句式配方
- 因果链：A则B，B故C，C所以D
- 全称判断：一切、尽、悉、莫不、百、千
- 感叹收尾：尤可恨也、甚可恶也

### 比喻配方
车轮轴心、媒婆说媒、烧火做饭、跷跷板、轴心生锈

### 否定配方
Step1 这是错的 → Step2 真正原因在这 → Step3 不这样做会死

### 教学配方
图形化（圆圈）+ 故事化（婴儿姹女）+ 生活化（媒婆车轮）+ 倒推法（症状→卡点→根源）
