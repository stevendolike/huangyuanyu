## 一、源头谱系：他受谁影响（向上看）

### 1.1 四圣：黄帝、岐伯、越人（扁鹊）、张仲景

| 源头 | 依据（【原文】） |
|---|---|
| **黄帝/岐伯（《内经》）** | 《四圣心源》天人解序："昔在黄帝，咨于岐伯，作《内经》以究天人之奥……慨自越人、仲景而后，秘典弗着，至教无传。"《素问悬解》自序："黄帝咨岐伯作《内经》，垂《素问》《灵枢》之篇，**医法渊源，自此而始**。"四圣心源自叙："医有黄帝、岐伯、越人、仲景四圣之书，争光日月。" |
| **越人（扁鹊，《难经》）** | 天人解序"慨自越人、仲景而后，秘典弗着"；《四圣心源》卷三·脉法解："**越人十难，实为定法**。"晚年专作《难经悬解》二卷（医书十一种目录，模块06）。 |
| **张仲景（《伤寒》《金匮》）** | 自叙"既解《伤寒》《金匮》……以继先圣之业"；卷二·六气解序："仲景既没，此义遂晦"；《伤寒悬解》自序"讵读仲景《伤寒》，一言不解，遂乃博搜笺注"；《金匮悬解》："《金匮要略》，张仲景论杂病之书……**为医杂病之祖本**。"其"少阴负趺阳为顺"的预后纲领直承仲景脉法（卷三·脉法解）。 |
| **临床启蒙** | 【素材】师从乡里名医于司铎；核心体系全凭自修经典，"私淑四圣"——无直接师承，属自我认祖。 |

**谱系定位**：黄元御是**经学式认祖**的典型——以"四圣"为经（医之六经），以《伤寒》《金匮》为"四子书"（欧阳兆熊序原文），把自己定位为"羽翼仲景，方之朱子"（欧阳兆熊序原文）。这与清代考据学风同步（他同时作《周易悬象》《道德经悬解》），本质是**用经学方法处理医学经典**。【推断+原文】

### 1.2 对前人的批判关系（指名道姓者）

| 对象 | 关系 | 依据 |
|---|---|---|
| **刘完素（寒凉派）** | 直接批判 | 【原文】《素问悬解》病机注："后世庸愚，乃引此以定百病之寒热。无知妄作，遂开杀运，最可痛恨也！**刘河间病机十九条。**"张琦后序："至于金元，刘完素为泻火之说……古法荡然矣。" |
| **朱丹溪（滋阴派）** | 直接批判 | 【原文】张琦后序："朱彦修作补阴之法……为丹溪之学者，与局方之学争。"《金匮悬解》："较之元人朱丹溪《金匮钩玄》，似较明晓"（贬其注）。《四圣心源》卷四："后世医术乖讹，乃开滋阴之门……祸流今古，甚可恨也"（不点名直指滋阴路线）。 |
| **张从正（攻下派）** | 未点名、立场间接对立 | 【推断】黄元御"禁大下"（"大下必伤中气"，skill误治禁区；麻黄升麻汤条"大下后……此最难治"），与攻邪派"邪去正安"路线相反；其名仅见赵克宣序引《儒门事亲》书名典故（【原文】"昔张从正撰《儒门事亲》十五卷，盖谓儒者能明其理以事亲"），未见黄元御亲笔指名批判。 |
| **李东垣（补土派）** | 部分承袭、无批判 | 【素材】"东垣是黄元御'重中'思想的重要学术渊源"；【学界共识】两者皆重脾胃，区别在东垣重升脾阳、黄氏重"脾升胃降"升降平衡（万方学位论文《黄元御中气升降理论探析》）。黄氏著作中无指名批判东垣的记录（grep未获）。 |
| **张景岳、叶天士** | 被后世序者划入对立面 | 【原文】欧阳兆熊序："吾之学，朱、张、刘、李之学也，吾之方，固出自**景岳《八阵》、叶氏《指南》**之所传也……不知黄氏所传者……四圣之心法，**彼则背而驰焉。异端曲学，足以害道**。"（此为同治元年重刊序立场，非黄元御本人文字，但构成其学派的对外定位。） |
| **孙思邈** | 汉后唯一例外推崇 | 【原文】《素问悬解》自序："愤检汉后医书，恨其不通。**通者，思邈真人《千金》一书而已。**" |
| **伤寒注家群（韩祗和、庞安时、朱肱等）** | 整体否定 | 【原文】《伤寒悬解》自序："纵观近古伤寒之家数十百种，岁历三秋，犹尔茫茫……群公著述，荒浪无归"；"韩祗和、庞安时之为也……朱肱《百问》，未绝纠牵。" |

**谱系要义**：黄元御的批判谱系呈"**两头通、中间断**"结构——向上只认四圣（+孙思邈一脉孤例），向下几乎全否（金元四家尤烈）；这与其"薪火无传、独我得传"的自我叙事互为因果。【推断】

### 1.3 易道经典：跨经典解经第三支（新增·周易悬象素材）

> 以下内容基于《周易悬象》原文（乾隆二十一年丙子九月庚午撰，欧阳兆熊序引四库提要）逐行验证，蒸馏版见 `modules/07_zhouyi-xuanxiang-distilled.md`，双向链路见 `references/37-zhouyi-knowledge-map.md`。
> 🔗 **更新**：补充《道德悬解》（乾隆二十一年二月二十一日撰，先于周易悬象七个月）——跨经典解经第三支由"医经+周易"扩展为"医经+周易+道德经"三支闭环。蒸馏版见 `modules/08_daode-xuanjie-distilled.md`，增强素材见 `references/38-daode-enhancement.md`。

**《周易悬象》不是旁注或闲笔，而是黄元御思想体系的宇宙论源头与方法论验证场**；《道德悬解》进一步证明此判断——**"太极→中气"推导链在道德经文本上有更直接的源头注脚**（章一注："无者，天地之太极。太极包含阴阳，阴阳之内有中气焉"）。

| 维度 | 内容 | 依据（【原文】） |
|------|------|------|
| **宇宙论直源** | 系辞上传第十一章注"阴阳未判，是为太极。太极判剖，分而为二，是生两仪。两仪升降，是生四象。阳升而化木火，阴降而化金水"——与《四圣心源》天人解"阴阳未判，一气混茫……清浊之间，是谓中气……水、火、金、木，是名四象"逐句对应 | 【原文】周易悬象系辞上传注 vs 四圣心源卷一·天人解 |
| **道断叙事同构** | 易学："经义全昧，议论俗腐，辞理庸烂" ≈ 医学："群公著述，荒浪无归"——同一套"道断→自我继承"叙事在两个领域同时运行 | 【原文】周易悬象序 vs 伤寒悬解自序 |
| **指名批判同构** | 易学：毛奇龄"穿连诸卦，牵缠辍转，甚无谓也" ≈ 医学：刘河间"无知妄作，遂开杀运，最可痛恨也"——先肯定对方才华→指出方法论错误→给出自己解法 | 【原文】周易悬象序 vs 素问悬解病机注 |
| **悬解自我立法同构** | 易学："水尽山穷，别开天地" ≈ 医学："以继先圣之业"——困境转化为解经合法性的宣言 | 【原文】周易悬象序 vs 四圣心源自叙 |
| **顿悟叙事同构** | 易学："每讶心开，恒惊须断" ≈ 医学："一言不解→博搜笺注→一夕豁然"——困中顿悟是悬解方法论的启动机制 | 【原文】周易悬象序 vs 伤寒悬解自序 |
| **跨经典声明** | "既解道德灵枢。六月中乃草周易"——将《周易悬象》《道德经悬解》《素问悬解》《灵枢悬解》置于同一"悬解"系列 | 【原文】周易悬象序 |
| **易医互证实例** | 说卦注引《素问》"在天为玄，玄生神。凡乾坤六子之化成万物，皆神之所为"——解易时自觉引用医经佐证 | 【原文】周易悬象说卦注 |
| **四库评价** | 《四库全书提要》评《周易悬象》："近人说《易》中独可谓学有根据"——纳入官方学术正统的证据 | 【原文】欧阳兆熊序引四库提要 |

**谱系定位更新**：黄元御的解经操作不限于医学，而是跨越医经（《素问》《灵枢》《难经》《伤寒》《金匮》）、周易、道德经三大经典集群的**经学式悬解**。"悬解"是其通用方法论——在所有经典上执行同一套操作：①宣判前人解释全错→②宣称自己困中顿悟恢复圣意→③以"悬解"之名重构文本。易-医推导链的发现进一步确认：《四圣心源》"一气周流"模型不是凭空创造，而是《周易》"太极→两仪→四象"宇宙论在人体上的应用转化——易书止于八卦，医书简化为四象+中气（土枢），完成从宇宙论到临床的降维映射。【推断+原文】

### 1.4 道德经经典：跨经典解经第三支之道德悬解（新增·道德悬解素材）

> 素材：《道德悬解》乾隆二十一年二月二十一日撰（早于周易悬象七个月），OCR全文1151行。蒸馏版见 `modules/08_daode-xuanjie-distilled.md`，增强素材见 `references/38-daode-enhancement.md`。

| 维度 | 内容 | 依据（【原文】） |
|------|------|------|
| **中气理论最直接源头** | 章一注"无者，天地之太极。太极包含阴阳，阴阳之内有中气焉……中气运转，阴降阳升，积阳为天，积阴为地"——比周易悬象系辞注更直接地点出"中气"之名 | 【原文】道德悬解·章一注 |
| **一气周流人体版完整推导链** | 章八注"谷神在中，先天之祖气……中气左旋而化己土，右转而化戊土。戊己运回，阳动升则化神魂，阴静降则化精魄。神藏于心，精藏于肾，魂藏于肝，魄藏于肺，脏腑悉备" | 【原文】道德悬解·章八注 |
| **坎离交济丹道源头** | 章七注"中者，道家之黄婆，在水火金木之交，处戊己二土之介，媒合婴姹（坎中阳气曰婴儿，即壬水；离中阴精曰姹女，即丁火），交媾龙虎（兑金为白虎，震木为青龙）" | 【原文】道德悬解·章七注 |
| **土德/中宫三书同证** | 章六注"信为土德，其位当中……土居无处，故寄旺四维而无专宫"≈周易悬象文言传乾"土旺四季，无专位也"≈四圣心源"中气者……所谓土也" | 【原文】三书对照 |
| **悬解方法论复现** | 大要"经文简错，其来久矣……今为详细移正，考部就班，使圣经复故"+"上经言道，下经言德"分卷重构 | 【原文】道德悬解·大要 |
| **跨经典声明** | 自叙"欲俟《灵枢》笺成，续为解之……请先为此注"——医经与道德经同属悬解工程 | 【原文】道德悬解·自叙 |
| **医经引用实证** | 章八注引《素问》"在天为玄，玄生神"——与周易悬象说卦注同句，三书互证 | 【原文】道德悬解·章八注 |

**三角闭环结论**：道德悬解（章一/章七/章八）+ 周易悬象（系辞十一/家人卦/文言传乾）+ 四圣心源（天人解/中气）共享同一套"太极→中气→四象→脏腑"宇宙模型——**"中气"理论的完整源头链：道德经（无者天地之太极，阴阳之内有中气）→周易（太极判剖生两仪，两仪升降生四象）→医书（清浊之间是谓中气，枢轴）**。三书同构不仅证明悬解是通用方法论，更证明医理体系是儒释道三家宇宙论的临床转化。【推断+原文】

## 二、影响谱系：谁承其学（向下看）

### 2.1 清代刊行链与"尊经派"接受史

- **张琦（阳湖宛邻书屋）**：道光十二年（1832）刊《四圣心源》等，【原文】后序"长沙而后，一火薪传，非自尊也"；"下可除河间丹溪之弊"。宛邻书屋本为最早流通精善本。【素材】
- **赵克宣、赵克宜（丹徒）**：道光壬寅（1842）校刊。【原文】两序。
- **欧阳兆熊（湘潭）**：同治元年（1862）序，【原文】"宗黄氏即以宗仲景，不宗仲景，黄岐之法不立，不宗黄氏，仲景之法不明"——尊经派纲领句。
- **冯承熙（阳湖）**：同治十一年（1872）新刻《素问悬解》，【原文】"自越人、仲景而后，罕有其伦"。
- **四库馆臣**：【原文】欧阳兆熊序"《四库全书提要》存目中已著录"；【素材】评《周易悬象》"近人说《易》中独可谓学有根据"。
- **谢观《中国医学源流论》**：【素材】推黄元御为"清代学派之首"；当代学界称其"清代气机升降派代表""尊经派集大成者"。【学界共识】

### 2.2 彭子益《圆运动的古中医学》（最直接的现代直系）

- 彭子益（1871—1949，云南大理人）《圆运动的古中医学》核心命题即"**中气如轴，四维如轮**"。
- 【学界共识】CNKI论文《彭子益医学圆运动学说与气机升降学术源流探讨》："核心思想是'中气如轴，四维如轮'，其来源于《黄帝内经》，取法仲景，旁参易水东垣，**承袭黄元御之论**"；百度百科《圆运动的古中医学》词条："其医学理论主要来源于清代黄元御的《四圣心源》"。
- 【原文对照】黄元御《四圣心源》卷一·天人解·阴阳变化："清浊之间，是谓中气，**中气者，阴阳升降之枢轴**，所谓土也……水、火、金、木，是名四象。**四象即阴阳之升降，阴阳即中气之浮沉。**"——"轴/轮"表述正是此模型的翻版。
- 2007年李可主校《圆运动的古中医学》由中国中医药出版社出版，助推当代"黄—彭"路线复兴。【学界共识】

### 2.3 郑钦安与扶阳派/火神派

- 【素材】传记断言："**扶阳派理论先驱——直接影响郑钦安火神派**"；"郑钦安的理论先驱"。
- 【学界共识/民间主流叙事】"郑钦安（火神派鼻祖）深受黄元御思想影响，尤其继承了其重视阳气、善用姜桂附等温热药的特点……黄元御的'一气周流，重视中阳'理论是火神派'重视命门真火'思想的重要源头。"【推断】须注明：郑钦安《医理真传》《医法圆通》未见明引黄氏原文，二者关系属"同尚姜桂附、重阳抑阴"的谱系性推断与主流叙事，非文本直证——此为学界尚有争议处，作答时宜表述为"一脉相承的主流说法，文本直证缺失"。
- 现代扶阳派（卢崇汉、李可等）以附子为特色，承火神派而下；李可同时是《圆运动的古中医学》主校者，两条线索在其处汇合。【推断+学界共识】

### 2.4 民国以来刊行、研究与"民间中医热"

- 【学界共识】民国间中医界仅流传《黄元御医书八种》刊本，《黄元御遗书三种》（素问悬解、灵枢悬解、难经悬解）长期"失传"，经麻瑞亭（黄氏五代传人，1903—1997）搜集与孙洽熙（六代，1940—）五年校勘，1990年人民卫生出版社出版**《黄元御医书十一种》170万字校勘本**，1992年获全国首届古籍整理图书丛书奖，成为现代通行标准本。【素材+学界共识】
- 后续版本：1999年中国中医药出版社《黄元御医学全书》；2019年人卫《黄元御医集》（灵枢悬解、难经悬解）；2012年孙洽熙主校《黄元御药解》。【学界共识】
- 流派建制：【素材】"黄元御长安学术流派"（杨震，2018年市级、2019年省级）；2024年"黄元御医学流派研究与传承专业委员会"成立；"南臧北黄"（与臧枚吉齐名）；医书清末已传入日本、朝鲜及南洋。
- 民间热证据（出自素材本身）：模块06《医书十一种》书末题记"**民间中医网黄元御医书整理小组校编**"——当代网络民间中医对黄氏著作的整理传播，正是"民间中医热"的实物印迹。【原文（素材校编题记）】

### 3.2 "土枢四象"模型在理论谱系中的独特性

【原文】《四圣心源》卷一·天人解·阴阳变化（模型总纲）：

> "阴阳未判，一气混茫。气含阴阳，则有清浊，清则浮升，浊则沉降……升则为阳，降则为阴……**清浊之间，是谓中气，中气者，阴阳升降之枢轴，所谓土也。**枢轴运动，清气左旋，升而化火，浊气右转，降而化水……水、火、金、木，是名四象。**四象即阴阳之升降，阴阳即中气之浮沉。**"

同书卷四·劳伤解·中气："中气者，**和济水火之机，升降金木之轴**，道家谓之黄婆。"【原文】

独特性可归纳为四点【推断+原文，学界共识佐证】：

1. **一元论**：把五行/五脏全部收摄于"一气"与"中气"，四象只是阴阳升降的阶段命名（"分而言之则曰四象，合而言之不过中气所变化耳"）——比传统五行生克更简约。
2. **动态化**：把五行相生克（"以气而不以质"）改写为**左升右降的环流**，生理病理皆描述为"轴—轮"运转的失常（左路不升/右路不降/中轴不运），这是"气机升降派"的范式标识。
3. **中土本位**：中气既是枢轴又是病机总闸（"四维之病，悉因于中气"），由此推出"土湿为本、崇阳抑阴"的治疗总纲（"泻水补火，扶阳抑阴，使中气轮转，清浊复位"）。
4. **儒道交融**：以"黄婆"（丹道喻中气）、"坎离交媾"、"祖气如太极"（天人解·脏腑生成"祖气者，人身之太极也"）入医理，并有《周易悬象》《道德经悬解》跨经典操作——医理、易理、丹道在其处合流。

**历史坐标结论**：黄元御不属于金元四家—温补—温病的任何主流谱系，而是在清中叶考据学背景下，以经学方法、一元动态模型重新立法，形成"**尊经派 + 气机升降派**"的交叉定位（谢观推为清代学派之首，当代学界称"清代气机升降派代表"）。其"土枢四象"经彭子益"中气如轴、四维如轮"直传至现代，又经火神派/扶阳派汇入当代临床主流——**就思想史而言，他是"圆运动"范式与"重阳"临床路线的共同理论枢纽**。【学界共识+推断】
