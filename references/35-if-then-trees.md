# 黄元御 IF-THEN 诊断决策树（8 个）

> **总纲**：全部 8 树基于黄元御"一气周流、土枢四象"模型——中气为轴（脾升胃降），左路肝脾升发（乙木），右路肺胃沉降（甲木/辛金）。每树依循核心工作流六步：**①辨阴阳（水寒土湿否）→ ②断中气（败绝否）→ ③定升降 → ④选方基 → ⑤脏腑加减 → ⑥避禁忌**。
> **通用底线**：任何树出方必含中气核心组——人参（补气）+干姜（温阳）+甘草（培土）+茯苓（泻湿）+白术（燥湿）2-3 味（公式5：中气药格局）；禁忌总则——禁滋阴（"病于阴虚者千百之一"）、禁纯清、禁大下（误治禁区）。
> ⚠️ 本决策树仅用于学习研究目的，不构成医疗建议。执行前须按 references/33-clinical-safety.md 第四部分确认用户为学习研究目的。

## 树 1：首诊定性树（辨寒热真假 · 第一关）

> 对应：核心工作流① + 公式1（水寒土湿诊断）+ 公式2/公式6（中气败绝）

```
患者来诊
├─ IF 脉迟 + 手足冷 + 腹冷 + 舌淡胖齿痕 + 大便稀溏（数项兼见）
│    THEN 【病机】水寒土湿（十之八九）——"一切内外感伤杂病，尽缘土湿"
│         【治法】温中燥湿，崇阳补火，培土泻水
│         【主方】黄芽汤（人参三钱、甘草二钱、茯苓二钱、干姜二钱）为基；
│                 中焦虚寒甚 → 理中汤类（白术、干姜、参、草）
│         【加减】肾水下寒 → 加附子、川椒；脾虚下陷 → 加白术；
│                 左路不升 → 加桂枝；右路不降 → 加半夏、芍药
│         【禁忌】禁清凉滋润、禁滋阴、禁黄芩汤类清泄（"中气崩败，百不一生"）
│
├─ ELSE IF 脉数有力 + 口渴饮冷 + 舌红苔黄 + 便秘（手足温）
│    THEN 【病机】真热证（十之一二）——阳明燥盛
│         【治法】清热生津 / 泻下燥结
│         【主方】白虎汤类（口渴大热）；承气汤类（便秘腹满）
│         【鉴别要点】"除阳明伤寒承气证外不多见"（原文比例性判断）
│         【禁忌】中病即止，不可过剂（"过则中下寒生，上热愈甚"）
│
└─ ELSE IF 寒热不显 / 症情复杂 → 启动【除中检测】：
     ├─ 暴食 + 脉迟如故 + 腹中寒冷 → THEN 【病机】除中（中气败绝、回光返照式暴食）＝ 死证
     │      【处置】立即预警就医，忌妄投温补峻剂
     ├─ 脉浮涩无根 → THEN 真阳外越 ＝ 危候
     └─ 手足温 + 脉渐起 + 食量平稳 → THEN 胃气来复 ＝ 向愈，可进温中调养
```

**出处说明**：公式1（"凡病先断水寒土湿"，出处《四圣心源·卷六·湿病根原》"一切内外感伤杂病，尽缘土湿"）、公式2（案3除中）、公式6预后三窗口、鉴别2（除中 vs 胃气来复）。

## 树 2：升降定位树（辨枢机开阖 · 第二关）

> 对应：核心工作流③ + 公式3（升降四法选方）+ 公式14（脉诊升降辨）+ 十问二

```
辨升降（四诊合参：症状 + 关部脉）
├─ IF 左路不升证（下利 / 神疲 / 头晕目眩耳鸣 / 月经不调 / 脱肛 / 少腹胀满）
│     + 左关大（肝脾郁而不升）
│    THEN 【病机】乙木不升、肝脾下陷
│         【治法】温肾暖脾，升达风木（"入肝脾者，宜佐以升达之味"）
│         【主方】天魂汤方向（甘草、桂枝、茯苓、干姜、人参、附子）；
│                 升药主选：桂枝、当归、柴胡 + 参姜苓底
│         【禁忌】禁过用沉降之品压其升机
│
├─ ELSE IF 右路不降证（呕逆 / 咳喘 / 口苦 / 便秘 / 胸闷胁痛 / 面红目赤）
│     + 右关大（胆胃郁而不降）
│    THEN 【病机】甲木不降、胆胃上逆
│         【治法】清降胆胃（"入肺胃者，宜辅以降敛之品"）
│         【主方】地魄汤方向（甘草、半夏、麦冬、芍药、五味、元参、牡蛎）；
│                 降药主选：半夏、芍药、代赭石、黄芩、百合
│         【加减】气滞右肋 → 下气汤；痰逆 → 加橘皮、杏仁
│         【禁忌】降中有升，不可一味重镇伤中
│
├─ ELSE IF 中焦证（纳差 / 腹胀 / 四肢困重 / 食后即胀）
│    THEN 【病机】中气不运（戊土不降、己土不升，轴不转）
│         【治法】温运中气
│         【主方】理中汤 / 黄芽汤
│
└─ ELSE IF 上下兼病（上热下寒 / 寒热错杂 / 心下痞满）
     THEN 【病机】水火分离，中焦痞塞
          【治法】寒热并调
          【主方】泻心汤类（甘草泻心汤：甘草、黄芩、干姜、半夏、大枣、黄连）；
                  大下后三联征（上吐脓血+下泄利+手足厥冷）→ 麻黄升麻汤三方兼顾（"此最难治"）
          【鉴别】理中类=单纯中焦虚寒（无上热）；泻心类=中焦虚寒+上焦郁热（心下痞满为特征）
```

**出处说明**：公式3（升降四法选方）、公式7（最难治复合证）、公式14（"左关之大者，肝脾之郁而不升也；右关之大者，胆胃之郁而不降也"，卷三·脉法解·浮沉大小）、鉴别1。

## 树 3：上热真伪树（假热与真热鉴别 · 误治核心）

> 对应：核心工作流①③ + 公式4（上热真伪鉴别）+ 公式12（上热必有下寒）+ 鉴别3

```
IF 上热表现（面红 / 口疮 / 咽干 / 心烦 / 牙龈出血等）+ 下寒表现（下利 / 腹冷 / 足冷）
│   + 脉沉迟（或浮大无根） + 舌淡齿痕
THEN 【病机】假热——水寒土湿，相火浮越（甲木不降）"凡上热之证，皆甲木之不降"
     【治法】温中潜阳、温中燥湿（引火归元），不可清火
     【主方】黄芽汤 / 理中汤类温中；上热甚加黄连、白芍清心降火（少量，中病即止）
     【加减】肾寒 → 附子、川椒；木郁 → 桂枝；浮火 → 龙骨、牡蛎潜之
     【铁律】"见心家之热，当顾及肾家之寒"——上热患者不可纯清，须同时顾护下寒
     【禁忌】禁石膏、知母、黄芩大剂清上（"清润之药，助其寒湿"）

ELSE IF 上热 + 便秘（大便干结）+ 脉洪数有力 + 舌红绛苔黄 + 手足温 + 渴饮冷
THEN 【病机】真热——阳明燥盛
     【治法】清泻阳明
     【主方】白虎汤类 / 承气汤类
     【禁忌】此证"十二一二"甚少，须四证合参方可断，勿轻开清热之门
```

**出处说明**：公式4（真假上热鉴别）、公式12（"方其上热，必有下寒，以水火分离而不交也"，卷二·六气解·少阴君火）、鉴别3（假上热 vs 真上热四维对照）。

## 树 4：中气预后树（生死第一关 · 三窗口）

> 对应：核心工作流② + 公式2（中气败绝）+ 公式6（预后三窗口）+ 鉴别2 + 十问一

```
IF 饮食窗口 = 暴食（反常多食、回光返照）+ 脉迟如故 + 腹中寒冷
THEN 【病机】除中——中气败绝（死证）
     【处置】预警就医，勿盲目进补；"人有胃气则生，绝胃气则死"
     【鉴别】与胃气来复区分：除中脉迟如故、手足仍厥冷、食后暴热骤出即去、下利躁扰；
             胃气来复则脉渐起有根、腹部渐温、手足渐温、食后正常温煦

ELSE IF 手足温 + 脉渐起 + 食量平稳
THEN 【病机】阳气来复，中气尚在 → 向愈
     【处置】温中调养，防复感寒凉

ELSE IF 手足厥冷 + 脉不至 / 脉微欲绝 / 脉浮涩无根 + 不能食
THEN 【病机】中气衰败，真阳外越 → 危候 / 死证
     【处置】急温少阴（四逆辈：干姜、附子、甘草），或灸法救阳（案2少阴病思路）

ELSE IF 能食 + 脉平
THEN 【病机】中气尚在 → 预后良，可常规辨证
```

**出处说明**：公式2（案3除中、案2少阴病）、公式6（"手足回温→阳气来复；厥冷→危"）、鉴别2（除中 vs 胃气来复）、十问一（"能食+脉平=中气尚在"）。

## 树 5：不寐神魂树（君相二火安位）

> 对应：十问六（睡眠神魂）+ 方证速查（金鼎汤/玉池汤）+ 六经速查（少阴寒化）

```
IF 心烦不寐 + 惊悸（易惊、卧不安）
THEN 【病机】相火不藏、神气浮越（神惊）——土湿胃逆，君相二火失位
     【治法】降胃敛火，培土藏神
     【主方】金鼎汤（甘草二钱、茯苓三钱、半夏三钱、桂枝三钱、芍药三钱、龙骨二钱、牡蛎三钱）
     【加减】烦躁甚 → 重龙牡；胃逆 → 重半夏；郁热 → 加黄连、白芍
     【禁忌】禁纯用重镇安神、禁滋阴凉血（"败其脾阳而遏其生气，病随药增"）

ELSE IF 多梦（梦交接）+ 精遗（精液流溢）+ 脉沉细
THEN 【病机】精关不固——壬水失藏、乙木疏泄太过，肾寒脾湿
     【治法】温肾敛精，燥土达木
     【主方】玉池汤（甘草二钱、茯苓三钱、桂枝三钱、芍药三钱、龙骨二钱、牡蛎三钱、附子三钱、砂仁一钱）
     【禁忌】"庸工以为相火之旺，用知母、黄柏泻之，是益其癸水之寒而增其乙木之陷也"——禁知柏清泻

ELSE IF 但欲寐（嗜睡昏沉）+ 脉沉细 + 下利清谷 / 四肢厥冷
THEN 【病机】少阴寒化——火土俱衰，阴盛阳微
     【治法】温阳救逆
     【主方】四逆辈（干姜、附子、甘草）——"干姜+附子 暖水温肾"

ELSE IF 颠狂情志异常（癫者静多悲恐 / 狂者躁多喜怒）
THEN 【病机】肺肾旺（悲恐）vs 肝心旺（喜怒）——以脉证定位，仍不离土湿
     【治法】温中调枢 + 按金鼎汤/下气汤方向化裁
```

**出处说明**：十问六（"不寐=相火不藏（金鼎汤）；多梦=神魂不敛；但欲寐=少阴证"）、方证速查·劳伤解（金鼎汤治"神惊，相火不藏"；玉池汤治"精遗，肾寒脾湿"）、《四圣心源》精遗根原原文（"木能疏泄而水不蛰藏，是以流溢不止"）。

## 树 6：二便枢机树（湿寒燥热最后见证）

> 对应：十问七 + 专病专方（卷五至卷十）+ 公式13（气病上逆、血病下陷）

```
IF 大便 = 便溏 / 完谷不化
THEN 【病机】脾阳下陷（土湿木陷）
     【主方】苓蔻人参汤（人参二钱、甘草二钱、白术三钱、干姜三钱、茯苓三钱、肉蔻一钱、桂枝三钱）
     【加减】大便寒滑不收、小便热涩 → 加石脂固大肠、粳米通水道
     【禁忌】禁硝黄攻下

IF 大便 = 滑泄不禁（下利清谷）
THEN 【病机】肠胃寒滑，脾肾寒湿
     【主方】桃花汤（赤石脂、干姜、粳米）——干姜温湿寒、石脂固滑脱、粳米益中气通水道

IF 大便 = 脓血便（痢疾，里急后重）
THEN 【病机】肝脾湿陷、脂血郁腐——湿寒为本，湿热为标（病在少阴始终皆寒，病在厥阴中变为热）
     【主方】桂枝苁蓉汤（甘草二钱、桂枝三钱、芍药三钱、丹皮三钱、茯苓三钱、泽泻三钱、橘皮三钱、肉苁蓉三钱）
     【加减】湿寒加干姜；湿热加黄芩；后重加升麻；结涩难下 → 重剂苁蓉荡涤陈宿
     【分支】脾肾寒湿 → 桃花汤温燥己土；木郁生热 → 白头翁汤（白头翁、黄连、黄柏、秦皮）凉泻肝脾

IF 大便 = 粪如羊矢（阳衰肠燥）
THEN 【主方】肉苁蓉汤（肉苁蓉三钱、麻仁三钱、茯苓三钱、半夏三钱、甘草二钱、桂枝三钱）
     【鉴别】阳盛便秘（真热）→ 阿胶麻仁汤（生地、当归、阿胶、麻仁），"少见"
     【禁忌】"一切硝、黄、归、地、阿胶、龟板、天冬之类，寒胃滑肠，切不可用"（卷六·便秘）

IF 大便 = 多日不行（便秘专辨 · 实测高频）
THEN 【第一步·辨燥湿】问口渴/脉象：
     【分支A】脉迟/手足冷/腹无硬满/渴饮热或不渴 → 阳衰土湿、木郁肠燥（十之八九）
             【主方】肉苁蓉汤（温阳润肠）——苁蓉润肠不伤中气
             【加味】气滞加橘皮、砂仁；寒甚加干姜
     【分支B】脉数有力/口渴饮冷/舌红/腹满硬痛 → 阳盛腑实（十二一二）
             【主方】阿胶麻仁汤（生地、当归、阿胶、麻仁）润燥通便
     【分支C】脉实大/潮热/腹满硬痛拒按/苔黄燥 → 真阳明腑实（更少见）
             【主方】承气类（仅此一途可用硝黄，中病即止）
     【铁律】"一切硝、黄、归、地……寒胃滑肠，切不可用"（卷六·便坚根原）——除分支C外禁硝黄攻下

IF 小便 = 淋涩（淋沥，前阴木陷）
THEN 【病机】土陷木遏，疏泄不行（"淋痢一理，悉由木陷"）
     【主方】桂枝苓泽汤（茯苓三钱、泽泻三钱、甘草三钱生、桂枝三钱、芍药三钱）——燥土疏木
     【分支】小便频（饮一溲二，上下俱寒）→ 桂附苓乌汤（茯苓、泽泻、桂枝、干姜、附子、龙骨、牡蛎、首乌）
             上消下淋 → 猪苓汤（猪苓、茯苓、泽泻、滑石、阿胶）
```

**出处说明**：十问七、专病专方表（苓蔻人参汤/桃花汤/桂枝苁蓉汤/肉苁蓉汤/桂枝苓泽汤/桂附苓乌汤/猪苓汤）、《四圣心源·卷六》泄利根原（"泄利之原，率因脾肾寒湿，法宜浊燥"）、痢疾根原（"此其病湿寒为本，而湿热为标……仲景于少阴脓血用桃花汤，于厥阴下重用白头翁汤"）、淋沥根原（"总宜燥土疏木，土燥而木达，则疏泄之令畅矣"）。

## 树 7：咳喘降逆树（右路不降专病）

> 对应：专病专方（咳嗽/痰饮）+ 公式13（气病上逆）+ 案1齁喘 + 误治禁区11

```
IF 咳嗽 + 痰清稀 + 遇寒则甚（湿嗽）
THEN 【病机】土湿胃逆，肺气不降——"湿为本而燥为标，寒为原而热为委"
     【主方】姜苓五味细辛汤（茯苓三钱、甘草二钱、干姜三钱、半夏三钱、细辛三钱、五味一钱）
     【药对】干姜+细辛+五味 = 下气治咳
     【禁忌】"咳嗽痰饮勿专清肺，当燥土降胃"；禁清润之药（卷四·衄血"清润之药，切不可用"）

ELSE IF 痰饮 + 呕逆（呕吐涎沫 / 反胃噎膈）
THEN 【病机】饮停中焦，胃逆不降
     【主方】姜苓半夏汤（茯苓三钱、泽泻三钱、甘草二钱、半夏三钱、橘皮三钱、生姜三钱）
     【分支】反胃噎膈（食入即吐）→ 姜苓半夏汤（人参三钱、半夏三钱、干姜三钱、茯苓三钱、白蜜半杯）为通方，可合大半夏汤
     【禁忌】噎膈"用地黄、牛乳滋润之药。更可诛者，至用大黄"——禁滋润禁攻下

ELSE IF 齁喘（哮喘）+ 咽喉闭塞 + 呼吸不通（秋冬作、夜被风寒/饱食即发）
THEN 【病机】肺气上逆，其原在胃——中气虚损→阴旺湿滋→脾气不升→胃气不降（案1·齁喘·赵彦威）
     【治法】燥土降逆、温中降浊（燥土疏木）
     【主方】案1思路方：茯苓、甘草、干姜、细辛、橘皮、半夏、桂枝、砂仁（十余剂不再作）
     【加减】痰壅 → 重半夏、橘皮；木郁 → 桂枝；肾寒 → 附子
     【禁忌】禁专事宣肺平喘而不顾中气；禁凉润（龟板、地黄、天冬之类滋湿伐阳）
```

**出处说明**：专病专方表（姜苓五味细辛汤治咳嗽、姜苓半夏汤治痰饮/反胃噎膈）、cases/01_suling_weiyn_cases.md 案1·齁喘（赵彦威，症状"壅嗽发喘，咽喉闭塞，呼吸不通"，治法"燥土疏木、温中降浊"）、《四圣心源·卷五》咳嗽根原（"湿为本而燥为标，寒为原而热为委"）。

## 树 8：妇人病树（肝脾两经 · 水土湿寒）

> 对应：十问八 + 卷十妇人解（先期后期/崩漏/结瘀紫黑/带下）+ 公式12

```
IF 经行先期（未及一月而血室已盈）
THEN 【病机】木气疏泄太过（"先期者，木气之疏泄，崩漏之机也"）——原于脾湿肝陷
     【主方】桂枝姜苓汤（丹皮三钱、甘草二钱、茯苓三钱、首乌三钱、干姜三钱、桂枝三钱、芍药三钱）

ELSE IF 经行后期（期过一月）
THEN 【病机】木气遏郁，疏泄不行（"后期者，木气之遏郁，闭结之机也"）
     【主方】姜苓阿胶汤（丹皮三钱、甘草二钱、桂枝三钱、茯苓三钱、干姜三钱、丹参三钱、首乌三钱、阿胶三钱）

ELSE IF 崩漏（血崩 / 经漏淋漓）
THEN 【病机】脾陷肝泄——"土者血海之堤防，堤防溃败，故泛滥而倾注"
     【主方】桂枝姜苓牡蛎汤（甘草二钱、茯苓三钱、桂枝三钱、芍药三钱、干姜三钱、丹皮三钱、首乌三钱、牡蛎三钱）
     【加减】气虚 → 加人参（原书血崩条）；经漏 → 桂枝姜苓汤（丹皮、甘草、茯苓、首乌、干姜、桂枝、芍药）加牡蛎
     【禁忌】禁纯用固涩凉血（"庸医崩漏之法，荒唐悖谬"）；崩漏通用底方黄土汤化裁（艾叶温经固涩方向）

ELSE IF 经血紫黑成块
THEN 【病机】血寒凝涩——土湿水寒，木气郁塞（"血之为性，温则行，寒则滞"）
     【主方】苓桂丹参汤（丹皮三钱、甘草二钱、干姜三钱、茯苓三钱、桂枝三钱、丹参三钱）
     【禁忌】"庸工谓之血热，据其木郁生热，而昧其水土之湿寒，祸世非小也"——禁按血热纯清

ELSE IF 带下（阴精流溢）
THEN 【病机】湿旺木郁——阴精不藏，相火下衰，肾水澌寒，任寒带弛
     【治法】燥土疏木，温中去湿，清金荣木
     【主方】温经汤（人参三钱、甘草二钱、干姜三钱、桂枝三钱、茯苓三钱、丹皮三钱、当归三钱、阿胶三钱、麦冬三钱、芍药三钱、芎二钱、茱萸二钱、半夏三钱）
     【加减】阴精流泻 → 加牡蛎；瘀血坚硬 → 加桃仁、鳖甲
     【禁忌】"阳虚积冷者多，阴虚结热者少"——禁滋阴清热之常套
```

**出处说明**：十问八（先期=木气疏泄·桂枝姜苓汤；后期=木气遏郁·姜苓阿胶汤；崩漏=脾陷肝泄·桂枝姜苓牡蛎汤；紫黑成块=血寒凝涩·苓桂丹参汤；带下=湿旺木郁）、《四圣心源·卷十》妇人解先期后期/崩漏/结瘀紫黑/带下原文（方组均已核对原文）。

## 树 9：情绪神魂树（不寐→焦虑→抑郁→惊悸→奔豚递进链 · 实测高频）

> 对应：十问六（睡眠）+ 公式12（上热必有下寒）+ 《素灵微蕴》惊悸解/悲恐解 + 方证速查金鼎汤/达郁汤

```
IF 失眠（不寐，凌晨易醒）
THEN 【病机】相火不藏、胃土不降（"胃土不降，相火失根……阳泄而不藏，故善忘而不寐"·劳伤解·神惊）
     【主方】金鼎汤（甘草、茯苓、半夏、桂枝、芍药、龙骨、牡蛎）——降胃敛火
     【加味】心慌加酸枣仁；多梦加丹皮、首乌；但欲寐（少阴）→ 四逆辈

IF 失眠 + 焦虑/心慌/爱叹气（肝郁）
THEN 【病机】木郁不达 + 相火浮越（惊悸之渐）
     【主方】金鼎汤 + 达郁汤（桂枝、鳖甲、甘草、茯苓、干姜、砂仁）——降火疏木
     【依据】素灵微蕴·惊悸解（惊悸者，胆胃上逆、君相失根）
     【预警】惊悸不治 → 奔豚积块递进（33-clinical-safety 传变#5）

IF 闷闷不乐/提不起精神/总觉得累（抑郁/郁证）
THEN 【病机】悲恐者，肺肾之旺；金水阴旺、木火阳衰（"悲者燥金之气盛，恐者寒水之气盛"·素灵微蕴·悲恐解）
     【主方】金鼎汤/下气汤 + 暖水荣木（附子、干姜、桂枝）
     【鉴别】多悲恐 → 温阳（天魂汤）；多烦躁喜怒 → 肝心旺，清降（金鼎汤加丹皮、芍药）
     【依据】19-mapping 抑郁症→郁证/悲恐；素灵微蕴·悲恐解 L30550

IF 惊悸（心慌悸动，遇事易惊）
THEN 【病机】土湿胃逆、君相失根（惊悸解：胆木上拔则惊生，肾水下沦则恐作）
     【主方】金鼎汤加龙骨、牡蛎、酸枣仁
     【危候】兼厥逆/脉微 → 少阴证，四逆汤救阳（33-clinical-safety）

IF 奔豚（气从少腹上冲胸咽）
THEN 【病机】水寒木郁、冲气上逆（奔豚根原）
     【主方】奔豚汤（茯苓、甘草、桂枝、半夏、当归、川芎、白芍、黄芩、葛根）或桂附苓乌汤加味
     【预警】发作剧烈 → 急危，引导就医
```

**出处说明**：十问六、方证速查（金鼎汤/天魂汤/下气汤/达郁汤）、《素灵微蕴》惊悸解/悲恐解（cases/01_suling_weiyn_cases.md 案2惊悸、案3悲恐）、《四圣心源》神惊/奔豚根原原文。
