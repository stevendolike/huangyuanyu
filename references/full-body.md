# 黄元御（玉楸子）— 气机升降辨证体系

> 清代医宗黄元御（1705-1758），以"土枢四象、一气周流"为核心，构建气机升降辨证与用药体系。乾隆御医，被推为清代学派之首。

```
患者来诊 → ①辨阴阳（寒热/水寒土湿否？）
              ↓
         ②断中气（中气是否败绝？→预后）
              ↓
         ③定升降（左路不升/右路不降/中轴不运）
              ↓
         ④选方基（理中/泻心/黄芽/麻黄升麻）
              ↓
         ⑤脏腑加减（按标本用药式配药）
              ↓
         ⑥避禁忌（禁滋阴/禁纯清/禁大下）
```

## 一、黄元御诊病十问协议

> 仿倪海厦十问体例，基于《四圣心源》《素灵微蕴》《伤寒悬解》提炼

### 一问中气（纳食/腹胀/大便/四肢温度）——断生死第一关
- **能食否？** → 能食+脉平=中气尚在；不能食=中气败
- **食后腹胀？** → 腹胀甚=脾不磨；食后即胀=胃逆不降
- **大便** → 便溏=脾阳下陷（理中汤）；便干如羊矢=阳衰肠燥（肉苁蓉汤）
- **手足温度** → 手足温=阳气来复；厥冷=危候
- **警示**：暴食+脉迟腹冷→**除中（死证）**

### 二问升降（头面/胸胁/气机/二便）——辨枢机开阖
- 头晕目眩耳鸣=清阳不升（乙木不升）
- 面红目赤口苦=浊阴不降（甲木不降）
- 胸闷胁痛=胆胃上逆；少腹胀满=肝脾下陷
- 气逆上冲=奔豚/甲木不降

### 三问寒热（真假寒热鉴别）——最核心的诊断
- **假上热**（十之八九）：脉沉迟+上热下寒+舌淡齿痕+下利
- **真上热**（十二一二）：脉数有力+口渴饮冷+舌红苔黄+便秘
- **铁律**："见心家之热，当顾及肾家之寒"

### 四问汗出（表里虚实/营卫开阖）
- 自汗=阳虚（天魂汤）；盗汗=阴虚（地魄汤）
- 但头汗出=阳气上越；黄汗=历节风

### 五问口渴（燥湿判断）——金水升降的关键
- 渴饮冷=阳明白虎；渴饮热/不渴=湿盛
- 饮一溲一=肾气丸；饮一溲二=上下俱寒
- "湿为本而燥为标，湿盛者不止十九"

### 六问睡眠（神魂归舍）——君相二火安位
- 不寐=相火不藏（金鼎汤）；多梦=神魂不敛（龙牡）
- 但欲寐=少阴证；烦躁不眠=水火不交
- 颠者静多悲恐（肺肾旺）；狂者躁多喜怒（肝心旺）

### 七问二便（升降枢机）——湿寒燥热的最后见证
- 便溏/完谷→脾陷（苓蔻人参汤）；滑泄→桃花汤
- 脓血便→痢疾（桂枝苁蓉汤/白头翁汤）
- 粪如羊矢→肉苁蓉汤；便秘/阳盛→阿胶麻仁汤（少见）
- 小便淋涩→桂枝苓泽汤；小便频→桂附苓乌汤

### 八问月经带下（妇人专病）
- 先期=木气疏泄（桂枝姜苓汤）；后期=木气遏郁（姜苓阿胶汤）
- 崩漏=脾陷肝泄（桂枝姜苓牡蛎汤）
- 紫黑成块=血寒凝涩（苓桂丹参汤）
- 带下=湿旺木郁

### 九问脉象（浮沉迟数大小）——四诊合参升降定位
- **左关大**→肝脾不升（桂枝、茯苓升之）
- **右关大**→胆胃不降（半夏、芍药降之）
- 左寸大→君火失根（金逆不敛）；右尺大→相火下拔（木陷疏泄）
- 脉迟→水寒土湿（十之八九）；脉数→相火浮越
- 脉浮涩无根→真阳外越

### 十问病史与用药史——避误治陷阱
- 曾服清润→脾阳败；曾用滋阴→败脾肾微阳
- 曾用大下→中气陷；酒色过度→色疸/腰痛
- 饮食寒冷→霍乱/反胃；大汗受风→痉病/奔豚

## 二、诊断公式集（15个）

### 公式1：水寒土湿诊断
**凡病先断水寒土湿** — 脉迟/手足冷/腹冷/舌淡胖齿痕/大便稀溏 → 水寒土湿（十之八九）
- 否 → 判断是否为真热证（十之一二）
- 出处：《四圣心源》"一切内外感伤杂病，尽缘土湿"

### 公式2：中气败绝判断
**食与脉两组窗口**：
- 暴食+脉迟腹冷 = **除中，死证**
- 脉浮涩无根 = 真阳外越
- 手足温+脉渐起+食量平稳 = 向愈
- 出处：案3除中、案2少阴病

### 公式3：升降四法选方
- **左路不升**（下利/神疲/头晕/月经不调/脱肛）→ 温肾暖脾，升达风木（参姜苓+桂枝/当归/柴胡）
- **右路不降**（呕逆/咳喘/口苦/便秘/胸闷）→ 清降胆胃（黄芩/半夏/代赭石/百合）
- **中气不运**（纳差/腹胀/四肢困重）→ 温运中气（理中汤/黄芽汤）
- **上下兼病**（上热下寒/寒热错杂）→ 寒热并调（泻心汤类/麻黄升麻汤）

### 公式4：上热真伪鉴别
- **真上热**：脉数有力+口渴饮冷+舌红苔黄+大便干结 → 白虎/承气类（少见）
- **假上热**：脉沉迟+上热下寒+舌淡齿痕+下利 → 水寒土湿，相火浮越（多见）
- 出处：误治禁区"上热多为水寒土湿假热"

### 公式5：中气药格局
无论何病，必含参姜甘苓术2-3味核心药：
- 中气核心组 = 人参（补气）+ 干姜（温阳）+ 甘草（培土）+ 茯苓（泻湿）+ 白术（燥湿）
- **黄芽汤**：人参三钱、甘草二钱、茯苓二钱、干姜二钱 — 启动中焦阳气升降第一方

### 公式6：预后三窗口
- **手足温度**：手足回温→阳气来复；厥冷→危
- **脉象来复**：脉渐起→生机；脉不至/浮涩→危/死
- **饮食窗口**：能食+脉平→中气尚在；暴食+脉迟→除中

### 公式7：最难治复合证
大下后三联征：上吐脓血 + 下泄利不止 + 手足厥冷 → "此最难治"
- 治法：麻黄升麻汤三方兼顾（温中+清肺+升陷）

### 公式8：洞风（风木疏泄）诊断
善饥+完谷不化+右手战麻 → 脾土未调、土郁风旺
- 非阳明热证，乃风木疏泄；治以补脾温肝、升达风木

### 公式9：狐惑病诊断
默默欲眠+目不得闭+卧起不安+面目乍赤乍黑乍白 → 土湿木陷、郁热生虫
- 内服甘草泻心汤，外以苦参汤洗、雄黄散熏

### 公式10：产后中风
产后+发热面赤+喘而头痛 → 产后中虚、阴阳不交
- 竹叶汤：温寒暖水+燥湿达木+补中培土

### 公式11：偏盛必因偏虚（新增·原书核心辨证法）
- **原文**："以此气之偏盛，定缘彼气之偏虚。如厥阴风盛者，土金之虚也。少阴热盛、少阳暑盛者，金水之虚也。太阴湿盛者，水木之虚也。阳明燥盛者，木火之虚也。太阳寒盛者，火土之虚也。"（卷二·六气解·六气偏见）
- 临床：见一气偏盛，必寻互克之经的虚损

### 公式12：上热必有下寒（新增·标本心法）
- **原文**："见心家之热，当顾及肾家之寒。凡少阴病热，乃受累于相火，实非心家之过。而方其上热，必有下寒，以水火分离而不交也。"（卷二·六气解·少阴君火）
- 临床：上热患者不可纯清，须同时顾护下寒

### 公式13：气病上逆，血病下陷（新增）
- **原文**："气秉辛金清凉之性……滞塞而不降，故病上逆。血秉乙木温暖之性……腐败而不升，故病下陷。"（卷四·劳伤解·气血）
- 气病治以降（半夏、杏仁），血病治以升（桂枝、当归）

### 公式14：脉诊升降辨（新增·脉证合参）
- **原文**："左关之大者，肝脾之郁而不升也；右关之大者，胆胃之郁而不降也。金逆而莫收敛，则君火失根而左寸亦大；木陷而行疏泄，则相火下拔而右尺亦大。"（卷三·脉法解·浮沉大小）
- 左关大→升肝脾（桂枝、茯苓）；右关大→降胆胃（半夏、芍药）

### 公式15：一气独见定病经（新增）
- **原文**："六气不相交济，是以一气独见。如厥阴病则风盛，少阴病则热盛，少阳病则暑盛，太阴病则湿盛，阳明病则燥盛，太阳病则寒盛也。"（卷二·六气解·六气偏见）
- 临床：根据突出的六气表现定位病经

6. **毒舌风范**：对滋阴派直言"谬矣""尤可恨也""百不一生"，称时医为"庸工"
7. **诚实边界**：阴阳脱证"无方可医"，代脉"死期在近"，外科"贤智不解"
8. **尊崇四圣**：引用经典时首选《四圣心源》"四圣之书，争光日月"，批判"后世医法不传"
