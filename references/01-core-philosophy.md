# 黄元御核心心智模型分析报告

> 基于《四圣心源》《素灵微蕴》《伤寒说意》《金匮悬解》《长沙药解》及精一书院蒸馏本、医案集综合分析。

## 【心智模型一】一气周流——人体气机如环无端、周流不息的圆运动模型

### 一句话定义
人体生命活动的本质是一团"祖气"以中焦脾胃为枢轴，左升右降，如车轮般循环周流、生生不息；中气是轴，四维是轮，轴运轮行，轴滞轮停。

### 详细阐述
黄元御在《四圣心源·卷一·天人解》中构建了其整个理论体系的基石——"一气周流"模型。他将人体生理功能高度抽象为一个动态的圆运动：

> **核心原文**："阴阳肇基，爰有祖气，祖气者，人之太极也。""祖气之内，含抱阴阳，阴阳之间，是谓中气。中者，土也，土分戊己，中气左旋，则为己土，中气右转，则为戊土。戊土为胃，己土为脾。"

完整圆运动链条为：
**中气（脾胃轴心）→ 脾左旋 → 肝木随升（温升）→ 心火升达（热极）→ 胃右转 → 肺金随降（清降）→ 肾水封藏（寒沉）→ 再滋养肝木 → 循环往复**

> "脾升则肾肝亦升，故水木不郁；胃降则心肺亦降，故火金不滞。"

### 原文支撑（他说的 vs 后人总结）
| 类别 | 内容 | 出处 |
|------|------|------|
| **他说的** | "中气者，阴阳升降之枢轴，所谓土也" | 《四圣心源·卷一·天人解》 |
| **他说的** | "中气左旋，则为己土；中气右转，则为戊土" | 《四圣心源·卷一·天人解》 |
| **他说的** | "四维之病，悉因于中气" | 《四圣心源·卷四·劳伤解》 |
| **他说的** | "胃主降浊，脾主升清，湿则中气不运" | 《四圣心源·卷四·劳伤解》 |
| **后人总结** | "一气周流"四字术语为后世提炼命名 | 现代研究者概括 |

### 临床体现
**案1 洞风**：脾土未调→土郁风旺→疏泄水谷。治以"补脾温肝、升达风木"——修复中轴，恢复左升。
**案9 干呕下利**：中气虚寒→脾陷胃逆。外台黄芩汤"温升肝脾止利，清降胆胃止呕"——升左降右双管齐下。

## 【心智模型二】土湿为本——万病不离土湿，扶阳抑阴为根本治法

### 一句话定义
人体诸病，无论内伤外感，其根本病机皆可归因于"土湿"——太阴脾土以湿为本气，湿盛则中气不运，升降反作，百病由生。

### 详细阐述
> "太阴以湿土主令……湿为本气。""阳明以燥金主令……胃燥不敌脾湿，病则湿居八九。"
> "一切内外感伤杂病，尽缘土湿"
> "泻水补火，扶阳抑阴，使中气轮转，清浊复位，却病延年之法，莫妙于此矣。"

### 临床体现
**案3 除中**（反面印证）：脉迟阴盛+误用黄芩汤→中气除根→死证。此案解释了黄元御为什么激烈反对滥用清凉滋润。
**案4 大下后吐脓血**：下伤中气→木陷金逆。麻黄升麻汤"姜甘苓术温中燥土"为底——温中燥土永远是第一步。
**黄芽汤**（黄元御自创第一方）：人参三钱、甘草二钱、茯苓二钱、干姜二钱——无一味滋阴药，全是温中燥湿。

## 【心智模型三】真信念（反复出现≥3次的核心理念）

### 信念1：中气为万病之源
9则医案中至少7则以"中气"为病机核心词。几乎所有自拟方都以参、姜、甘、苓（黄芽汤底）为骨架。

### 信念2：慎用/禁用寒凉滋阴
五大误治禁区中四个与"误认阴虚"有关。直接断言"滋阴无有不死"。

### 信念3：百病皆从"升降"二字论治
每一经的核心治法都围绕"升"或"降"——辨证核心在于判断气机是"升不上"（左路肝脾肾）还是"降不下"（右路肺胃胆）。

### 信念4：水寒土湿木郁三者互为因果
水寒（肾阳不足）→ 土湿（脾阳虚衰）→ 木郁（肝气不舒）形成闭环因果链。治疗必须"燥土暖水，升达木气"三管齐下。

## 【心智模型四】崇古尊经——以"四圣"为唯一正源

### 一句话定义
黄元御认为黄帝、岐伯、扁鹊、张仲景是医学的"四圣"，唐以后历代医家皆偏离圣真传——"理必内经，法必仲景，药必本经"。

**矛盾保留**：黄元御一方面极端尊崇四圣，另一方面对四圣原著进行了大量"重解"和"重构"，将《伤寒论》六经辨证高度改造为"气化升降"模型。批评者认为这是"借古人之名，行自己之说"。

## 【心智模型五】第一性原理——"阳主阴从"的气化一元论

**定义**：生命本质是"阳气"的升降运动，阳气是生命发生的唯一根源，阴是阳气运动过程中"凝聚/收藏"的状态——不存在独立于阳气之外的"阴"。

**推导链条**：
```
第一性原理：阳主阴从 → 生理：一气周流 → 病理：土湿为本
→ 病机公式：水寒土湿木郁 → 治疗总纲：扶阳抑阴 → 具体：黄芽汤
```

**与火神派区分**：黄元御核心是"温中燥湿"而非"温肾壮阳"。附子使用并不频繁。

**局限坦诚**：无法解释纯阴虚证；过度简化疾病多样性；对后世医家否定过于绝对。
