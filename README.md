# 黄元御中医辩证skill

> 清代医宗黄元御（玉楸子，1705-1758）"土枢四象、一气周流"气机升降辨证与用药体系技能。
> ⚠️ 本技能仅用于学习研究目的，不构成医疗建议。出方须先确认学习研究目的。

## 一、技能简介

以"一气周流，土枢四象"为核心，构建黄元御气机升降辨证与用药体系。覆盖：

- **核心理论**：一气周流、中气升降、土湿为本、崇阳抑阴（宇宙论三书同源：《周易悬象》系辞注 + 《道德悬解》章一注 + 《四圣心源》天人解）
- **诊断体系**：诊病十问协议、15个诊断公式、8棵IF-THEN决策树
- **方剂体系**：一基四方（黄芽/天魂/地魄/乌肝/兔髓）+ 专病专方 + 六气治法方 + 核心药对
- **知识底座**：《黄元御医书十一种》全文 + 《四圣心源》+《长沙药解》+《周易悬象》全文 + 《道德悬解》全文

## 五、安全边界（强制）

1. **第一闸门**：出方前必须确认用户为学习研究目的，非对自己和他人进行治疗
2. **学习研究声明**：每题回答附"⚠️ 学习研究目的，不构成医疗建议；若为真实病症请就医"
3. **诚实边界**：无依据不硬编（如穴位非主线、现代病名按映射+推演并注明）
4. **禁联网搜索**：基于内置知识库回答，超出范围诚实说明
