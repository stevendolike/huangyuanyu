2. 火金上逆→辛金不降：清火润金（麦冬/百合 + 枇杷叶/苏子）
3. 水寒土湿→乙木不升：温肾暖脾（附子/肉桂 + 黄芪/当归）
4. 中气不运→百病由生：温运中气（理中汤为基）
